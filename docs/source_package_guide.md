# Source package guide

See the root README for installation and the public interface. `recorded/` retains
the final local experiment source separately from the portable `experiments/`
interface. See `recorded_release.md` for the final landing profile and scene setup.

`RELEASE_MANIFEST.json` contains SHA-256 hashes for the published source files.
`SOURCE_ORIGINS.json` retains the original source-packaging provenance; the original
private runtime archive is not part of this Git repository.
